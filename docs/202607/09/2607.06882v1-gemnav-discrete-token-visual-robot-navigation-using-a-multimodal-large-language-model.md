## 摘要
基于大型预训练模型的视觉导航策略迄今遵循一个常见配方：专用视觉编码器、定制动作头以及在数千小时的跨具身数据集上训练。我们质疑这一配方是否必要。本文介绍GemNav，一种视觉机器人导航策略，它仅通过语言塔上的低秩自适应（LoRA）适配冻结的多模态大语言模型（MLLM），用于短至中期航点导航，无需辅助视觉编码器或连续回归头。航点和分类导航信号共享由语言模型头生成的单一离散令牌词汇表，而软解码辅助损失恢复了纯交叉熵训练丢弃的度量结构。在单个8.7小时开放语料库（规模比竞争训练集小约三个数量级）上，该策略零样本迁移到四个物理上不同的未见环境，并在涵盖开放停车场、障碍停车场、室外化工长院和室内仓库的20次真实世界试验中，在目标0.25-0.42米范围内停止。基于短图像历史的条件改善离线指标，但未带来机器人收益，表明一旦预训练视觉特征到位，时间上下文带来的提升存在上限。这些结果表明，冻结MLLM的离散令牌适配可以为基础模型机器人导航提供数据高效、可部署的替代方案。

## Abstract
Visual navigation policies built on large pretrained models have so far followed a common recipe: a dedicated visual encoder, a bespoke action head, and training on thousands of hours of cross-embodiment datasets. We ask whether this recipe is necessary. In this paper, we introduce GemNav, a visual robot navigation policy that adapts a frozen Multimodal Large Language Model (MLLM) for short-to-medium horizon waypoint navigation using Low-Rank Adaptation (LoRA) on the language tower alone, with no auxiliary visual encoder and no continuous regression head. Waypoints and categorical navigation signals share a single discrete token vocabulary generated by the language-model head, and a soft-decoded auxiliary loss recovers the metric structure that pure cross-entropy training discards. On a single 8.7-hour open corpus, roughly three orders of magnitude smaller than competing training sets, the policy transfers zero-shot to four physically distinct unseen environments and stops within 0.25-0.42m of the goal across 20 real-world trials covering an open carpark, an obstacle carpark, a long outdoor chemical yard, and an indoor warehouse. Conditioning on short image histories improves offline metrics but yields no robot benefit, pointing to a ceiling on what temporal context adds once pretrained vision features are in place. These results indicate that discrete-token adaptation of frozen MLLMs can provide a data-efficient, deployable alternative for foundation model robot navigation.

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
将导航重构成**离散令牌序列预测**问题：用MLLM的语言模型头（stock LM head）直接输出路径点（waypoint）的量化令牌和分类停止信号，而不是附加任何连续回归头。

### 关键技术细节
1. **冻结MLLM + LoRA适配**：
   - 使用**Gemma-4-E2B-it**模型，视觉塔（vision tower）完全冻结，仅在语言塔的线性层上施加**LoRA**（r=32, α=16）。无额外的视觉编码器或3D编码器。
2. **离散动作令牌化**：
   - 将连续轨迹和停止信号统一表示为**18个令牌的序列**（<bot_traj> + 8个x,y路径点值令牌 + <eot_traj>），或3个令牌的停止信号（<bot_traj> + 停止令牌 + <eot_traj>）。
   - 每个坐标轴在 [-15m, 15m] 内均匀量化64个bin（bin宽0.469m）。使用Gemma 4的保留<unusedN>令牌扩充词汇表。
3. **软解码辅助损失**：
   - 纯交叉熵损失（CE）会丢失值令牌之间的序关系。作者引入**软解码回归损失**：对路径点位置的logits进行softmax，再与bin中心加权求和得到连续预测值，计算MSE损失（λ=0.1）。这使相邻bin错误受轻微惩罚，将验证ADE降低23%。
4. **目标采样**：
   - **距离基采样**（distance-based）：从轨迹中均匀采样目标，距离范围0.5-14m，避免了固定帧偏移导致的短视先验（固定帧采样会导致实际部署失败）。

### 模型架构（简述）
输入：当前图像 + 可选的过去帧图像 + 可选的目标图像/2D坐标（通过<goal_coord>令牌），经过Gemma 4的冻结视觉编码器和语言模型，输出离散路点令牌序列。无连续回归头。

## 6. 论文的主要结论与发现
1. **冻结MLLM的离散令牌适配可部署**：仅用8.7小时数据训练的GemNav，在20次真实世界试航中，所有pose-only模态均成功（5/5），最终位移0.25-0.42m，与人类操作相当。
2. **视觉编码器瓶颈可被绕过**：冻结的预训练MLLM视觉特征足以支撑导航，无需重新训练或添加专用视觉编码器。
3. **负结果**：增加短视觉历史（h=2或4）改善离线ADE，但在真实部署中无收益，甚至四帧历史导致性能下降（4/5成功），因时间上下文促使策略延迟当前运动。
4. **离散动作令牌 + 软解码回归损失**比纯CE显著更好（ADE降低23%）。
5. **距离基目标采样**优于帧对齐采样：虽然后者域内ADE更低，但导致真实部署完全失败（所有模态立即停或漂移）。
6. **在障碍环境中显著优于OmniVLA**：OmniVLA在需要绕行时完全丧失目标跟踪能力，而GemNav保持成功。

## 7. 优点
- **数据效率**：仅用8.7小时开放数据，远低于OmniVLA的9500小时，仍具强泛化性。
- **架构简洁**：无专用视觉编码器、无连续回归头、无额外3D编码器。直接利用现成MLLM的语言头输出离散令牌，统一了动作和停止信号。
- **软解码辅助损失**创新：在离散令牌框架中恢复度量结构，不需额外参数。
- **诚实报告负结果**：公开讨论了历史深度带来的离线-部署矛盾，并提供了控制实验解释。
- **零样本跨模态融合**：在训练中未联合训练ego+pose模态的情况下（阶段C1之前），模型能零样本地融合图像和坐标目标，归功于共享的<goal_coord>令牌。
- **开源友好**：公布了TokenWalker数据集及训练/评估细节。

## 8. 不足与局限
- **跨具身迁移未测试**：所有实验在同一机器人（Spot）上，不同机器人的泛化能力未知。

- **动作表征局限**：
  - 仅输出2D (x,y) 路点，无法表示原地旋转。

- **推理效率**：尽管优化后A100上约421ms，但在边缘平台（Orin、Thor）仍较慢，可能限制实时性。
