## 摘要
基于记忆的离散视觉-语言导航（VLN）智能体必须在部分可观测性下运行，但即使是强大的冻结主干网络在测试时仍然脆弱。两种常见的失败模式是：记忆读取时存在过时的历史证据，以及在动作选择过程中出现低效的局部回溯。我们提出了DART-VLN，一个针对离散VLN的无训练测试时控制框架。DART-VLN结合了测试时记忆衰减（一种读取侧记忆重加权规则，在不重写存储内容的情况下抑制过时和冗余证据）与防循环正则化（一种轻量级的下一跳惩罚，旨在在动作选择过程中阻止即时逆转）。该框架不引入新的可学习参数，并且保持已学习的主干网络不变。在R2R和REVERIE上的实验显示出一致的模式：仅使用衰减能在读取侧获得稳定的收益，而衰减加防循环则实现了最佳的整体质量-效率权衡，在关键设置中产生更短的轨迹、更低的运行时间和改进的导航性能。行为分析进一步证实，防循环正则化减少了局部回溯，并在冻结主干网络下提高了路径效率。总体而言，结果表明，适度的测试时控制可以使基于记忆的离散VLN更可靠、更高效，而无需重新训练。

## Abstract
Memory-based discrete vision-language navigation (VLN) agents must act under partial observability, yet even strong frozen backbones remain vulnerable at test time. Two common failure modes are stale historical evidence at memory readout and inefficient local backtracking during action selection. We present DART-VLN, a training-free test-time control framework for discrete VLN. DART-VLN combines Test-Time Memory Decay, a read-side memory reweighting rule that suppresses stale and redundant evidence without rewriting stored content, with Anti-Loop Regularization, a lightweight next-hop penalty that discourages immediate reversals during action selection. The framework introduces no new learnable parameters and leaves the learned backbone unchanged. Experiments on R2R and REVERIE show a consistent pattern: decay-only provides stable read-side gains, while decay+anti-loop achieves the best overall quality-efficiency trade-off, yielding shorter trajectories, lower runtime, and improved navigation performance in key settings. Behavioral analysis further confirms that anti-loop regularization reduces local backtracking and improves path efficiency under frozen backbones. Overall, the results show that modest test-time control can make memory-based discrete VLN more reliable and efficient without retraining.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
### 2.1 核心思想
提出 **DART-VLN** 框架，包含两个互补的测试时干预机制：
- **测试时记忆衰减（Test-Time Memory Decay）**：在记忆读取端对每个存储槽进行重加权，抑制过时和冗余证据，而不改写已存储内容。
- **防循环正则化（Anti-Loop Regularization）**：在动作选择时基于下一跳（graph next-hop）施加轻量级惩罚，阻止立即回溯和重复访问。

### 2.2 关键技术细节
#### (1) 测试时记忆衰减
- **槽元数据**：对每个记忆槽 \(m_i\) 维护三个轻量级元数据：
  - 槽龄 \(a_i = t - t_{\text{last}_i}\)（距上次刷新步数）
  - 访问次数 \(c_i\)
  - 新颖性 \(n_i\)：通过指数移动平均平滑特征变化，\( n_i^{(t)} = \rho n_i^{(t-1)} + (1-\rho)\nu_i \)，其中瞬时新颖性 \(\nu_i = \text{clip}(1 - \cos(f_i^{\text{old}}, f_i^{\text{new}}), 0, 1)\)，\(\rho=0.5\)。
- **读取权重公式**：
  \[
  w_i = \text{clip}\left( \exp(-\lambda a_i) \cdot \left(1 - \alpha \frac{c_i}{c_i+1}\right) \cdot (0.5 + 0.5 n_i), \; w_{\min}, w_{\max} \right)
  \]
  - 三项因子：**近期性**（指数衰减过期槽）、**重复抑制**（减少高频访问槽的权重）、**新颖性偏好**（鼓励特征仍在变化的槽）。
  - 参数默认：\(\lambda=0.12,\ \alpha=0.15,\ w_{\min}=0.35,\ w_{\max}=1.0\)。
- **边界说明**：仅读取端重加权，存储内容不变，区别于写端直接改写记忆。

#### (2) 防循环正则化
- **惩罚定义**：设候选动作 \(v\) 的图下一跳为 \(h(v)\)，则惩罚项为：
  \[
  p_t(v) = \beta_{\text{back}} \cdot \mathbb{I}[h(v)=v_{t-1}] + \beta_{\text{rev}} \cdot \mathbb{I}[\text{visit}(h(v)) \ge k]
  \]
  - 第一项惩罚**立即回溯**（下一跳返回上一步位置）。
  - 第二项惩罚**重复访问**（下一跳被访问超过 \(k=2\) 次）。
  - 参数默认：\(\beta_{\text{back}}=0.22,\ \beta_{\text{rev}}=0.06\)。
- **调整后得分**：\(s_t'(v) = s_t(v) - p_t(v)\)，然后通过 \(\arg\max\) 选择动作。
- **应用范围**：仅测试时、确定性的argmax推理，不修改主干网络或停止头。

#### (3) 算法流程（文字描述）
1. 初始化轨迹和访问计数。
2. 每步：编码指令和当前观测；计算记忆读取权重 \(w_i\)；聚合加权记忆得到候选得分 \(\{s_t(v)\}\)。
3. 对每个候选 \(v\)，计算下一跳 \(h(v)\)，根据公式得到惩罚 \(p_t(v)\)，更新得分 \(s_t'(v)\)。
4. 选择 \(\arg\max_v s_t'(v)\)；若选STOP则返回轨迹；否则执行转移，更新访问计数和记忆元数据。

1. **decay-only** 提供稳定的读取端收益：在R2R val unseen上NE从2.83降至2.59，运行时间减少约21%；REVERIE上SR、SPL、RGS等均略有提升，运行时间减少约31%。
