## 摘要
视觉-语言模型（VLM）代理已推进了零样本物体目标导航，但单帧推理使其缺乏具身导航所需的跨步行为感知，导致反复出现死胡同停滞、室内循环以及接近检测目标时绕路等失败。基于提示的补救措施会膨胀多子模块剧情的令牌预算，并且仍然难以编码本质上属于空间信号的角、地图单元和视点坐标。本文提出SkillNav，一种基于VLM的可扩展行为技能框架，它将现代VLM导航器已经维护的好奇心价值图视为可写入的基底，复合技能在其上以零令牌成本刻写行为记忆。技能根据其行为权威级别分为三个层次：用于比例重新加权的软缩放、用于区域级保证的下界提升、以及用于阈值触发的强制动作的硬覆盖，并在固定的组合顺序下跨层级协作，从而在技能之间建立可预测的、声明的优先级。这种设计将能力改进转变为技能注册：新行为无需重新训练VLM或干扰现有技能即可插入，为持续改进开辟了路径。一个最小的提示通道用类别级语义提示补充了分数级技能，产生了一种双表示设计，其中空间记忆存在于地图上，语义记忆存在于短提示中。无需训练，SkillNav在MP3D（25.5）、HM3D v0.1（39.3）和HM3D v0.2（43.2）上建立了新的SPL最先进水平，相比最强先前方法SPL绝对值提升高达6.0，并在HM3D v0.1（69.7）和v0.2（75.9）上实现了最高成功率。

## Abstract
Vision-Language Model (VLM) agents have advanced zero-shot object-goal navigation, yet single-frame reasoning leaves them without the cross-step behavioral awareness an embodied navigator requires, producing recurring failures such as dead-end stalls, in-room loops, and circuitous approaches to detected targets. Prompt-based remedies inflate token budgets across multi-submodule episodes and still struggle to encode inherently spatial signals such as angles, map cells, and viewpoint coordinates. In this paper, we propose SkillNav, an extensible behavioral skill framework for VLM-based navigation that treats the curiosity value map already maintained by modern VLM navigators as a writable substrate on which composable skills inscribe behavioral memory at zero token cost. Skills are stratified into three tiers by their level of behavioral authority, namely soft scaling for proportional reweighting, lower-bound boost for region-level guarantees, and hard override for threshold-triggered forced actions, and cooperate across tiers under a fixed composition order that establishes a predictable, declared priority among skills. This design turns capability improvement into skill registration: new behaviors plug in without retraining the VLM or disturbing existing skills, opening a path for continual refinement. A minimal prompt channel complements the score-level skills with category-level semantic hints, yielding a dual-representation design in which spatial memory lives on the map and semantic memory in short prompts. Training-free, SkillNav establishes new state-of-the-art SPL across MP3D (25.5), HM3D v0.1 (39.3), and HM3D v0.2 (43.2), improving SPL by up to 6.0 absolute over the strongest prior method, and achieves the highest Success Rate on HM3D v0.1 (69.7) and v0.2 (75.9).

## 1. 核心问题与整体含义

*   **研究动机**：现有基于视觉-语言模型（VLM）的零样本物体目标导航（ObjectNav）代理主要依赖单帧推理，缺乏跨步行为意识，导致三种典型重复性失败——死胡同停滞、在已探索房间内无效循环、以及检测到目标后因步长过大而丢失目标。
*   **整体含义**：这些问题源于空间信息未在行为层面被有效记忆。将历史行为序列串行化为文本提示的方法会快速膨胀token预算，且无法精确编码角度、地图格子等空间信号。本文旨在以零额外token成本实现跨步行为记忆，从而显著提升导航效率与成功率。

## 2. 方法论

*   **核心思想**：利用现代VLM导航器已维护的“好奇心价值地图”（curiosity value map）作为可写入基底，通过分数级操作（score-level operators）将行为记忆直接刻写在地图上，无需重新训练VLM。
*   **关键技术细节——三级技能干预框架**：
    1.  **软缩放（Soft Scaling）**：对每个方向分数乘以一个系数 $\gamma_k$ 并钳制到软上限 $\alpha_{\text{soft}}$，用于温和地重新加权方向偏好（如抑制已探索方向、鼓励未探索出口）。
    2.  **下限提升（Lower-Bound Boost）**：当目标被连续两次确认时，在地图上以该位置为中心、半径 $r$ 的圆形区域内将分数直接设为最大值 $\alpha_{\max}$，确保目标位置不会被遗忘。
    3.  **硬覆盖（Hard Override）**：当检测到死胡同（位移长期低于阈值）或震荡循环（ABAB模式）时，完全忽略原分数，强制指定方向并将失败方向清零，实现强制脱困。
*   **组成顺序与稳定性**：按“软缩放 → 下限提升 → 硬覆盖”的固定顺序执行，保证三个性质：下限保持、覆盖主导、缩放中立。新技能只需声明所属层级，即可安全注册，无需担心冲突。
*   **双表示设计**：空间记忆由分数地图承载，语义记忆由极短的类别级经验提示（固定长度，$O(1)$ token）承载，两者互补。

## 6. 主要结论与发现

*   SkillNav在所有三个基准上均取得了SPL最先进水平：MP3D 25.5、HM3D v0.1 39.3、HM3D v0.2 43.2，相比最强先前方法MerNav分别提升6.0、2.4、5.6绝对点。
*   在HM3D v0.1和v0.2上取得了最高成功率（69.7和75.9），在MP3D上成功率略低于MerNav（48.3 vs 50.8），但SPL大幅领先（25.5 vs 19.5），说明SkillNav以牺牲极少成功率为代价大幅提升路径效率。
*   消融表明：提示通道主要降低假阳性（-1.2%），技能层主要降低最大步数超时（-1.7%），二者互补。
*   更强骨干（Gemini-3-Flash）在视觉模糊类别（电视、床、植物）上提升显著，而在视觉明确类别（沙发、马桶）上趋于饱和，说明剩余瓶颈主要在感知而非导航策略。

## 7. 优点

*   **零额外token成本**：行为记忆直接写入已有价值地图，不增加任何推理开销。
*   **可组合可扩展**：新技能只需声明层级并按固定顺序注册，无需重新训练VLM或干扰现有技能。
*   **双表示解耦**：空间记忆与语义记忆分离，各自处理不同失败模式，设计清晰。
*   **无需训练**：完全基于规则和VLM推理，易于复现和部署。
*   **稳定性保证**：显式定义了操作符顺序及三个不变性，防止技能冲突。
*   **持续改进路径**：通过注册新技能即可增强能力，便于未来不断补充行为库。

## 8. 不足与局限

*   **感知瓶颈依然存在**：对于视觉模糊的目标（如关闭的电视、混在杂物中的植物），VLM检测能力不足导致成功率提升有限，本文未从感知层面给出创新。
*   **实验覆盖有限**：只测试了两种VLM骨干（Gemini-3-Flash和Qwen2.5-VL-7B），且仅在HM3D v0.2上做了详细消融，MP3D上缺乏类似分析。
*   **未报告算力成本**：虽然无需训练，但VLM推理本身的延迟和显存消耗未讨论，可能部署成本较高。
*   **技能设计依赖手工规则**：阈值（如停滞位移阈值、探索覆盖率阈值）需要手工调参，泛化到更多环境可能需额外调整。
*   **成功率在长距离场景略有牺牲**：MP3D上SR略低于MerNav，说明强制锚定目标可能牺牲了部分晚期成功机会。
