## 摘要
端到端的视觉语言导航（VLN）借助因果视觉语言模型，能够直接将指令和第一人称观察映射到行动，但标准的行为克隆仅监督下一动作，并未明确训练策略状态以预测未来视觉结果。我们首先提出一个诊断性问题：如果在训练和测试时将专家轨迹的未来图像作为特权输入提供给策略，这一额外的视觉证据是否有助于选择当前动作？（在实际部署中，测试时无法获得这些专家轨迹的未来图像，因此我们仅将此设置用作特权输入诊断。）答案是肯定的；这一合理性检查表明，未来观察能够提供丰富且可操作的线索。随后，我们提出一个可部署的问题：在不借助推理时未来图像的情况下，是否仍能通过仅将压缩的未来视觉潜变量作为训练监督来从未来信息中获益？我们提出了未来状态条件化VLN（FSC-VLN），该方法添加了一个未来查询令牌，并通过一个仅在训练时存在的目标分支（训练后移除）将其隐藏状态与前方Δ步的冻结视觉嵌入对齐。在R2R验证集未见过的场景中，FSC-VLN在两种训练数据机制下相较于StreamVLN风格的基线在SR/OSR/SPL指标上均有提升，尤其在长程任务中效果更显著；消融实验进一步支持了双查询设计（将未来查询与动作查询分离）。

## Abstract
End-to-end vision-language navigation (VLN) with causal vision-language models can map instructions and egocentric observations directly to actions, but standard behavior cloning supervises only the next action and does not explicitly train the policy state to be predictive of future visual outcomes. We first ask a diagnostic question: if the policy is given an expert-trajectory future image as privileged input at training and testing time, is that additional visual evidence useful for choosing the current action? (These expert-trajectory future images are unavailable at test time in real deployment, so we use this setting only as a privileged-input diagnostic.) The answer is yes; this sanity check shows that future observations can provide rich, actionable cues.   We then ask a deployable question: without accessing future images at inference, can we still benefit from future information by using a compressed future visual latent only as training supervision? We propose Future-State-Conditioned VLN (FSC-VLN), which adds a future-query token and aligns its hidden state to a frozen visual embedding $Δ$ steps ahead via a training-only target branch that is removed after training. On R2R val-unseen, FSC-VLN improves SR/OSR/SPL over a StreamVLN-style baseline under two training-data regimes, with larger gains on long-horizon episodes; ablations further support the dual-query design (separating future and action queries).

- **研究领域**：视觉语言导航（Vision-Language Navigation, VLN），特别是在连续环境（VLN-CE）中，智能体需根据自然语言指令和第一人称视觉观测序列执行导航动作。
- **现有局限**：主流方法采用因果视觉语言模型（VLM）通过行为克隆（Behavior Cloning）直接学习动作映射，但仅监督下一步动作，**未明确训练策略状态去预测未来视觉结果**。这使得导航中局部动作虽合理，但长期累积误差难以纠正，尤其在长程任务中。
- **核心问题**：能否在不依赖测试时未来观测的前提下，通过训练阶段利用未来视觉信息来提升可部署的在线策略？
- **整体含义**：本文验证未来观测包含可用的导航线索，并提出一种轻量级训练方法，在不改变推理结构的情况下利用未来信息监督，显著提升长程导航性能。

## 2. 方法论
### 核心思想
- 在端到端VLM导航策略中，插入**未来查询（future query）** token，训练时将其隐状态与未来Δ步观测的冻结视觉嵌入对齐；推理时移除该目标分支，仅保留未来查询作为因果前缀。
- 同时引入**动作查询（action query）** token，其隐状态作为动作解码的条件，可注意力到未来查询，实现“未来条件化”的动作生成。

### 关键技术细节
- **模型架构**：基于Qwen2-7B因果Transformer + 冻结的SigLIP视觉编码器 + MLP投影器（均冻结）。
- **序列构造**：每步在线上下文Ct后，依次插入可学习未来查询qF、动作查询qA，再接动作令牌序列at。因果注意力下，qF可总结上下文，qA可关注qF。
- **未来目标构建**：使用共享冻结视觉编码器处理专家轨迹中未来Δ步的观测ot+Δ，经均值池化得到目标嵌入z*_{t+Δ}，并停止梯度（stop-gradient）。
- **对齐损失**：将qF隐状态hF通过投影层g映射到低维空间，与目标嵌入的投影计算L1损失：L_future = ||g(hF) - g(z*)||_1。权重λF=0.1。
- **总训练目标**：L_total = L_LM (交叉熵动作预测) + λF * L_future。
- **推理**：仅保留在线上下文和两个查询token，单次因果预填充后自回归解码动作令牌；无未来观测、无目标编码器、无额外前向传播。
- **冻结策略**：视觉编码器和投影器全程冻结，仅优化语言模型和查询嵌入，确保目标空间稳定。

### 公式与算法流程（文字说明）
1. 提取当前观测和历史观测的视觉令牌，与指令令牌组成上下文Ct。
2. 拼接Ct、qF、qA（均为d维可学习向量），输入Qwen2后得到隐状态序列。
3. 从隐状态中取出qF位置hF，通过投影层与未来目标嵌入计算L_future。
4. 从qA位置隐状态开始，经LM头解码首个动作令牌，后续动作自回归生成，计算交叉熵损失。
5. 总损失反向传播更新语言模型参数及qF、qA嵌入。
6. 推理时仅执行步骤1-2（无未来目标分支），然后解码动作。

1. **未来观测蕴含可操作线索**：将专家轨迹未来图像作为特权输入后，SR从29.96%提升至71.77%，证明未来信息高度有用。

3. **长程改善显著**：长程片段（>10m）上SR提升2.93~3.85、OSR提升3.67~7.15、SPL提升2.52~3.70；短程几乎不变，验证预测性监督对抗长期误差累积的有效性。

## 7. 优点
- **轻量且实用**：训练时仅增加未来目标分支，推理时只需额外两个查询token（共2×d参数），无额外计算成本，易于集成到现有VLM导航管线。
